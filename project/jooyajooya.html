# UX/UI 설계 및 디자인  기여도 100%

# 진행 날짜  2024.02.01 ~ 2024.03.12

노년층을 타겟으로 한 음성 상담 플랫폼 웹앱 사이트를 제작하였다. 원래 진행하고 있던 프로젝트팀에 디자인을 할 수 있는 사람이 없어 외주 요청을 받아 제작이 진행되었다.
업체와 직접 소통하면서 색상부터 시작해서 위계질서를 고려하며 UI, 사용자의 관점을 고려하며 UX를 설계하였다. 웹앱 디자인 및 개발 작업을 진행하며 배포까지 진행하였다.

# 문제점 및 해결 과정

# UX/UI

외주 작업을 진행하기 전 UI가 디자인 되어 있었지만 밑에 사진처럼 UI마다 동일성이 없었고 색감, 위계질서가 고려되어 있지 않았다. 그리고 레이아웃이 일정하게 구성되어 있지 않아서 새로 설계 및 디자인해야 하는 상황이었다.

위 사진이 메인 UI

위 사진이 회원들이 사용하는 상세페이지들이다.

업체에서 처음에 메인 색상을 민트색을 요구해서 민트색상으로 베이스 색감을 정한 후 레이아웃을 설계하면서 디자인 해 나갔다. 메인 UI의 width 값도 불명확하게 짜여져 있어 넓게 잡아 맞추어주었다.

메인 UI를 다 설계한 후 다른 UI들을 순조롭게 제작하는 과정에서 width 값을 휴대폰 넓이로 맞추어달라는 요구사항이 생겼다.

기존에 설계했던 UI들을 IPhone SE 기종으로 맞추어서 다시 제작해야 되서 두 번 제작하는 문제점이 발생하면서 일을 효율적으로 처리하지 못한 이슈가 발생했다.

그리고 작업을 진행하던 도중 두 번째 문제점이 발생했다. 업체에서 요구했던 메인 색상인 민트색에서 분홍색으로 메인 색상을 변경해 달라는 요구가 들어왔다.

노년층을 타겟으로 잡았기 때문에 민트색보다는 분홍색이 사용자 관점에서 조금 더 다가가기 쉬운 색상이라고 느껴졌다. 전체적으로 폰트 크기를 크게 잡았으며 버튼을 배치할 때, 잘 보이는 중앙 위치에 배치를 하였다.

# 개선 후 UI

위 사진들이 업체의 요구사항들을 모두 반영한 후 나온 UX/UI다.
휴대폰 사이즈로 width값을 조절한 후 메인 색을 적용한 후 최종으로 웹앱으로 배포한 후 사용자가 볼 수 있는 UI다.

# 느낀 점

이전에 진행했던 프로젝트와 폴더구조가 많이 달랐다. 컴포넌트가 복잡하게 분리되어 있어 폴더구조를 파악하는데에 시간이 많이 소요됐다. 그래서 폴더 구조를 만들 때 최대한 잘 이해할 수 있게 만드는게 좋다는 것을 느꼈다. 그리고 ClassName도 겹쳐 CSS 중복 현상도 발생했다. 내가 메인이 아닌 서브로 참여해 디렉토리 구조를 당장 변경할 수 없었지만 이후에 졸업작품과 같이 내가 만들 때, 좋았던 디렉토리 구조를 참고하여 만들 수 있었다.

외주 작업을 하다 보니 처음 요구사항대로 제작해도 요구사항이 변경되면 변경된 것에 다시 맞추어 제작해야 하는 문제점이 있었다. 중간에 요구사항이 변경될 수도 있기 때문에 그래서 처음부터 완벽하게 제작하기 보다는 전체 틀을 먼저 잡는 것이 효율적이다는 것을 느꼈다.
